# Construction Tools

Status: **TBD**

A dedicated tool specification is reserved here so tooling remains separate from materials and consumables in BOM/cost calculations.

No exact canonical tool list is recorded in the current specification context. Until individual tools and requirements are explicitly fixed, the domain model and calculators must **not invent tool brands, models, quantities or productivity norms**.

Future entries should distinguish at minimum:

- reusable tools/equipment
- rented equipment
- installation tooling tied to a specific operation
- PPE/safety equipment where it is part of the construction process

This file is intentionally marked TBD rather than filling missing decisions with assumptions.
