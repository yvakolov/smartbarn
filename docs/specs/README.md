# Smart Barn — Construction Specifications

This directory is the canonical human-readable construction specification for the current Smart Barn prototype.

## Specifications

- `00-house-concept.md` — general house concept and scope
- `01-zero-floor.md` — zero/ground floor field construction
- `02-exterior-walls.md` — exterior SIP walls
- `03-roof.md` — roof geometry and structural rules
- `04-window-openings.md` — window opening datums
- `05-entrance-doors.md` — entrance door openings
- `06-interior-doors.md` — interior door standards
- `07-tools.md` — construction tools
- `08-consumables.md` — fasteners, foam and treatment materials

## Status convention

`FIXED` means the rule was explicitly agreed and may be used by the domain model/calculators. `DEFERRED` means the topic is intentionally outside the current implementation stage. `TBD` means no exact value has yet been fixed and software must not invent one.
