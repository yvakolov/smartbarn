# Начало работы

Smart Barn — модульная платформа для проектирования и конфигурирования строительных систем.

На текущем этапе основным рабочим функциональным модулем является редактор перекрытия.

## Основные области приложения

- авторизация;
- основная оболочка приложения;
- редакторы функциональных модулей;
- настройки языка и темы;
- документация.

## Язык и тема

По умолчанию интерфейс использует русский язык. Также поддерживается английский.

Тема по умолчанию — системная. Пользователь может выбрать светлую, тёмную или системную тему в настройках.
